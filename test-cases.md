# Test Cases for Linq Profile and Contact Save Flow (Visitor Perspective)

This file outlines manual test cases for the feature flow on https://linqapp.com/ashu_reddy?r=link: viewing a profile and attempting to save contact info as a visitor. The test cases are based on the visitor view, where a user can view the profile, click "Exchange Contact," and either share their info (phone/email) or download the contact directly as a vCard. The test cases are ordered to follow the natural user flow, from loading the profile to completing the contact exchange and handling post-exchange actions, followed by validation, edge cases, and additional scenarios.

## Test Cases
